# NoteQuest Digital — MVP

Protótipo web/PWA sem backend, feito para transformar o fluxo do Manual NoteQuest em um sistema jogável.

## O que já funciona
- criação aleatória de aventureiro por Raça + Classe Básica;
- PV, Tochas, Moedas, Provisões e magias;
- criação aleatória de uma das seis masmorras básicas;
- geração procedural de segmentos ao abrir portas;
- portas, armadilhas, salas, monstros e combate;
- magias básicas;
- mapa visual simples da exploração;
- cidade: descanso, compra de tochas e provisões;
- salvamento no navegador via localStorage;
- interface responsiva com tema escuro/cinemático.

## Próxima etapa
Adicionar todas as tabelas do Mundo Expandido como dados, sem misturar regra com interface: mapa hexagonal mundial, localidades, eventos, ruínas, portais, outros mundos, raças, classes avançadas, magias, mercenários, animais, prédios, política, guerra e multiplayer.

## Como executar
Abra `index.html` em um navegador moderno. Para uso como PWA/instalação e módulos ES em alguns navegadores, prefira servir a pasta por um servidor local simples.
